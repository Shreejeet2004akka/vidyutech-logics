# Vidyutech Logics — Free Website

This is a static, responsive company website built with HTML, CSS and JavaScript.

## Files

- `index.html` — website content and structure
- `style.css` — design, layout and responsive styling
- `script.js` — menu, animations and year
- `assets/logo.png` — your supplied Vidyutech Logics logo

## Before publishing

1. Open `index.html` in a browser and check the site.
2. The contact email is already configured as `vidhyut.designing@gmail.com`.
3. Later we can add WhatsApp, phone number, address, social links, project photos and a portfolio.

## Publish for ₹0 with GitHub Pages

1. Create a free GitHub account.
2. Create a new public repository, for example `vidyutech-logics`.
3. Upload all files and the `assets` folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save and wait for GitHub Pages to publish.
8. Your free address will be similar to:
   `https://YOUR-GITHUB-USERNAME.github.io/vidyutech-logics/`

No paid hosting is required.
